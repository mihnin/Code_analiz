# AI сканер — Интеллектуальный анализатор исходного кода

## Назначение

**AI сканер** — корпоративное веб-приложение для автоматизированного анализа исходного кода, функциональных спецификаций (ФС) и технических заданий (ТЗ) с помощью больших языковых моделей (LLM).

Приложение решает три ключевые задачи предприятия:

| Роль | Задачи | Типовые действия |
|------|--------|------------------|
| **Информационная безопасность** | Выявление уязвимостей, аудит кода | Анализ уязвимостей (OWASP Top 10, CWE), комплексный аудит безопасности |
| **Консультант / Аналитик** | Понимание бизнес-логики, документирование | Объяснение логики кода, формирование ТЗ на доработку, создание ТЗ с нуля |
| **Разработчик** | Повышение качества кода | Рефакторинг, оценка качества (1–5), анализ производительности |

### Поддерживаемые языки

- **ABAP** — SAP-системы (проверки авторизации, динамические запросы, модульные функции)
- **1С** — платформа «1С:Предприятие» (привилегированный режим, внешние обработки, типовые/нетиповые конфигурации)
- **Python** — серверные приложения, скрипты, Data Science
- **JavaScript** — веб-приложения, фронтенд, Node.js

## Ключевые возможности

### Два режима работы с LLM

| Параметр | Облачный режим | Локальный режим |
|----------|---------------|-----------------|
| **Провайдер** | DeepSeek API | LM Studio, Ollama, Xinference |
| **Протокол** | OpenAI-compatible | OpenAI-compatible |
| **Модели** | deepseek-chat, deepseek-reasoner | Любые локальные модели (Qwen, LLaMA, Mistral и др.) |
| **Контекстное окно** | До 64K токенов (по умолчанию) | Авто-определение из метаданных модели |
| **Сеть** | Требуется интернет | Работает полностью офлайн (КСПД) |

### Поддержка reasoning-моделей

Приложение автоматически определяет «думающие» модели (DeepSeek-R1, Qwen3, QwQ и др.) и отображает процесс рассуждения в отдельной сворачиваемой секции с подсчётом токенов. Это позволяет видеть цепочку мыслей модели (Chain-of-Thought) и контролировать качество анализа.

### Система вложений

- **Файл контекста** — пользовательские данные (код, спецификации) прикрепляются к запросу
- **Файл инструкций** — корпоративные стандарты, регламенты, политики безопасности встраиваются в системный промпт и сохраняются с шаблоном

### Управление токенами

Визуальный счётчик токенов в реальном времени показывает распределение контекстного окна:
- Системный промпт + пользовательский ввод + вложения + история чата + резерв для ответа
- Цветовая индикация: жёлтый при >80%, красный при превышении лимита

### Дополнительно

- Потоковый вывод (SSE streaming) — ответ появляется в реальном времени
- Рендеринг Markdown с подсветкой таблиц, списков, блоков кода
- Кнопки копирования для каждого ответа и каждого блока кода
- История анализов (до 50 сессий) с поиском и возможностью продолжения диалога
- Настраиваемые промпты для каждой роли и действия
- Горячие клавиши: Ctrl+Enter (запуск), Escape (отмена), Tab (отступ)

## Архитектура и развёртывание

### Полная автономность

Приложение не использует внешних зависимостей — ни CDN, ни npm-пакетов, ни фреймворков. Всё написано на чистом HTML5 + CSS3 + Vanilla JavaScript (ES6+).

### Развёртывание

Скопируйте **4 файла** в одну папку:

```
index.html    — интерфейс (структура + 30 встроенных SVG-иконок)
styles.css    — стили (тёмная тема через CSS custom properties)
app.js        — вся логика приложения
logo.png      — логотип
```

Откройте `index.html` в браузере. Готово.

Никаких серверов, сборщиков, установки. Работает с файловой системы, из сетевой папки, с флешки.

### Работа в закрытых сетях (КСПД)

Приложение спроектировано для корпоративных сетей без доступа в интернет. В локальном режиме подключается к LLM-серверу внутри сети (LM Studio, Ollama, Xinference) по протоколу OpenAI API. Никакие данные не покидают периметр организации.

## Экономическая эффективность

### 1. Сокращение трудозатрат на code review

| Метрика | Ручной процесс | С AI сканером | Экономия |
|---------|----------------|---------------|----------|
| Аудит безопасности (1000 строк) | 4–8 часов специалиста ИБ | 5–15 минут + верификация 30 мин | **80–90%** времени |
| Объяснение бизнес-логики кода | 2–4 часа аналитика | 5–10 минут генерации + 20 мин редактуры | **75–85%** времени |
| Формирование ТЗ на доработку | 1–3 рабочих дня | 10–30 минут + доработка 2–4 часа | **60–80%** времени |
| Оценка качества кода | 2–3 часа senior-разработчика | 5–10 минут | **85–90%** времени |
| Рефакторинг с рекомендациями | 4–8 часов | 10–20 минут + ручная реализация | **50–70%** общего времени |

|-----------------|---------------------------|--------------------------------------|

### 5. Неколичественные выгоды

- **Стандартизация** — единый формат отчётов по безопасности, ТЗ и code review для всей организации
- **Снижение порога входа** — junior-специалисты получают экспертные подсказки уровня senior
- **Скорость реагирования** — аудит безопасности нового кода за минуты, а не дни
- **Сохранение знаний** — промпты с корпоративными стандартами (файлы инструкций) кодифицируют экспертизу организации
- **Безопасность данных** — в локальном режиме код не покидает периметр, что критично для организаций с режимом коммерческой/государственной тайны
- **Нулевая зависимость от вендоров** — нет привязки к конкретной LLM; работает с любой моделью через OpenAI-совместимый API

## Быстрый старт

### Облачный режим (DeepSeek)

1. Получите API-ключ на [platform.deepseek.com](https://platform.deepseek.com)
2. Откройте `index.html` в браузере
3. Перейдите в **Настройки** → режим **Облако** → вставьте API-ключ
4. Выберите роль, язык, действие → вставьте код → **Ctrl+Enter**

### Локальный режим (LM Studio / Ollama / Xinference)

1. Установите и запустите LLM-сервер с нужной моделью
2. Откройте `index.html` в браузере
3. Перейдите в **Настройки** → режим **Локальная модель** → укажите адрес сервера
4. Нажмите **Обновить список моделей** → выберите модель
5. Выберите роль, язык, действие → вставьте код → **Ctrl+Enter**

Адрес локальной модели по умолчанию: `http://172.16.33.12:9997`
